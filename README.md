# Business Outcome Monitoring demo

Clickable prototype of Blueprint's Business Outcome Monitoring feature for Power Automate Desktop estates, built on Lovable's TanStack Start template (React 19, Vite, Tailwind v4 with preflight off). The demo itself is plain React with its own stylesheet under `src/demo/` and `src/demo.css`.

- `bun install` (or `npm install`), then `npm run dev` to run it; `npm run build` to check it compiles.
- Read `PROJECT_BRIEF.md` first. It holds the rules the demo must keep, the eight scenarios, and where each piece lives.
- `LOVABLE_KNOWLEDGE.md` is the text to paste into Lovable's Project Knowledge so its edits keep those rules.

Synthetic data generated in the browser from a fixed seed. Not a product build.
